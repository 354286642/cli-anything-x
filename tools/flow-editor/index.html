工作流可视化编辑器

编辑 flow.json，实时预览编译出的 SKILL.md。

从左上角下拉框选择一个工作流，或点击「＋ 新建」创建。

基本信息

工作流的「身份证」。名称、标题、描述、触发词决定它如何被识别与路由；溯源信息记录对应的后端接口与前端页面，便于回溯。

溯源信息（sourceRefs）

业务目标（businessGoal）

适用场景（scenarios）

流程结束接口调用示例

前置条件

执行流程前必须满足的条件。如已登录系统、项目已配置、依赖数据已存在等，可拖拽排序。

成功标准

如何判定流程执行成功。如接口返回预期数据、页面跳转到目标页等，逐条列出，可拖拽排序。

流程步骤

把业务拆成有序的步骤卡片。顶层是大卡片，点标题展开后可编辑详情；需要细分时在卡片内「添加子步骤」。某一步仅在特定条件下执行？填写「触发条件」，卡片会出现 橙色标记 与「当 …」标签。拖动卡片左侧的 ⠿ 手柄 即可调整顺序。

字段定义

表单所有字段的「字典」。在这里定义每个字段的名称、类型、是否必填、显示条件、值来源与含义。步骤通过「关联字段」引用它们，编译器据此生成 SKILL.md 的字段表与字段依赖图。上方标签切换分组，「表格 / 依赖图」切换视图。


        


        
        

          
接口列表

          
流程用到的所有接口清单。每个接口给定 ID、用途、方法、路径，步骤通过「关联接口」引用，卡片上会显示接口名称而非 ID。

          

        


        
        

          
话术模板

          
用户用一句自然语言触发整个流程。每个模板是一张独立卡片，【】 内为可替换内容，方括号 [] 内的片段可省略。

          

        


        
        

          
Agent 引导策略

          
告诉 Agent 如何引导用户填表。哪些字段可预填、默认值从哪来、哪些必须追问、哪些行为被禁止，都在这里配置。


          
预填规则（prefillRules）

          
字段 → 默认值来源 → 是否可改。预填后须回显并允许用户修改。

          


          
必须追问（mustAsk）

          
无默认值、不可编造的字段，缺失时引导用户补充。

          

          

          
严禁行为（forbidden）

          
如「随机生成」「测试数据」「随便填」等措辞或行为。

          

          
        


        
        

          
错误处理

          
出错时怎么办。列出错误码或异常场景，以及对应的恢复动作（如重新登录、重试、提示用户）。

          

        


        
        

          
领域知识

          
补充的业务背景与「坑」。字段词典摘要、边界规则、易错点，支持 Markdown 行内语法。

          

          
        


        
        

          
参考文件

          
编译后写入 reference/ 目录的三份附录。字段字典、话术示例集、验证脚本。左侧编写，右侧实时渲染。
